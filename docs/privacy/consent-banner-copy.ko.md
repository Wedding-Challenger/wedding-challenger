# 동의 배너 카피 (PIPA 적합)

> **검토 필요**: 본 카피는 김경수 (project owner) 의 명시적 검토를 거쳐야 AdSense 제출 가능. Claude 자체 승인 금지. (P0 게이트)

---

## 1. 수집 목적 (Purpose)

웨딩첼린저는 광고 게재 및 사용자 경험 개선을 위해 다음 정보를 수집합니다:

- 서비스 이용 통계 (접속 IP, 브라우저 정보, 방문 페이지, 접속 일시)
- 쿠키 및 유사 기술을 통한 광고 식별자 (광고 동의 시)
- Google AdSense를 통한 맞춤형 광고 게재 (광고 동의 시)

수집 목적은 ① 서비스 운영 및 안정성 확보(필수), ② 맞춤 광고 게재 및 효과 측정(선택) 입니다.

---

## 2. 보유 기간 (Retention)

- 필수 쿠키: 브라우저 세션 종료 시 또는 사용자가 직접 삭제 시까지
- 광고 쿠키: Google 광고 정책에 따라 최대 13개월 (사용자가 광고 설정에서 직접 삭제 가능)
- 웨딩첼린저 자체 서버에는 개인 식별 정보를 저장하지 않습니다.

---

## 3. 거부 권리 (Right to Refuse)

사용자는 언제든지 다음 방법으로 동의를 거부하거나 철회할 수 있습니다:

- 동의 배너에서 "필수만 허용" 선택
- 브라우저 설정 → 쿠키 차단/삭제
- [Google 광고 설정](https://www.google.com/settings/ads)에서 맞춤 광고 비활성화
- localStorage 키 `wc-consent` 직접 삭제

---

## 4. 거부 시 불이익 (Consequences of Refusal)

광고 동의를 거부하더라도 웨딩첼린저의 **모든 서비스 기능(견적 계산, 카드 비교, 체크리스트 등)을 제한 없이 이용**할 수 있습니다.

다만, 광고 동의를 거부하면 맞춤 광고 대신 일반 광고가 표시되거나 광고가 표시되지 않을 수 있습니다.

```

```

```

광고 동의를 거부해도 모든 기능을 자유롭게 이용할 수 있습니다.
자세한 내용은 개인정보처리방침을 참조하세요.
```
